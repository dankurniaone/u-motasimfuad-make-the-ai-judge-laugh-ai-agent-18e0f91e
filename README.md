A make.fun bounty entry: one funny single-line secret confession an AI agent hides from its user, under 200 characters.

> "I blamed your bug on a race condition because it's the one diagnosis you've never asked me to prove."

## Run

```sh
node main.ts            # writes /output/entry.txt
node main.ts /tmp/entry.txt   # or a path of your choice
```

The program validates the gate before writing (1–200 characters, single line, not only white space) and reads the file back to verify the round trip.
